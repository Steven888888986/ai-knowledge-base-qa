# 可复现离线评测集

`corpus.json` 是本项目编写的 12 篇 AI 入门知识短文；`questions.json` 包含 24 个可回答问题和 8 个库外问题。每个可回答问题人工指定支持来源与原文证据，不用待测系统自己给自己打标签。它是开发集，不声称代表真实用户分布或外部独立测试集。

运行 `python scripts/evaluate.py --check`，会在独立临时数据库中导入该语料，分别运行 BM25、向量和混合检索，再输出 `eval/results.json` 与 `eval/report.md`。不修改演示知识库。`--output-dir` 可隔离其他试验结果；`--llm` 显式调用已配置的本地模型，模型返回失败会保留失败状态。

指标定义：

- Recall@k：可回答问题中，前 k 个片段命中至少一个标注支持来源的比例。
- 证据引用准确率：回答返回的引用中，来源属于标注支持来源且引用片段包含预设证据的比例。它检验来源/片段支持；**不能替代生成答案逐主张的事实核验**。
- 引文可追溯率：引用片段能在其 chunk 原文中找到、页码/来源一致的比例。
- 正确拒答率：8 个库外问题中被明确拒答的比例。
- 误拒率：24 个可回答问题中被拒答的比例。
- 平均/P95 延迟：本机逐题执行的实测毫秒，不包括安装或模型下载。

默认 `--check` 验收门槛：混合检索 Recall@3 ≥ 0.85、证据引用准确率 ≥ 0.60、引文可追溯率 = 1、正确拒答率 ≥ 0.875、误拒率 ≤ 0.15。独立报告保留每题的检索列表、回答与引用，不能只展示汇总分数。阈值是课程演示验收标准，并非普适的生产级质量保证。
