# 编程：Python 列表与元组

示例问题：Python 列表和元组有什么区别？

Python 列表是可变序列，能够修改已有元素，或添加、删除元素；元组是不可变序列，创建后不能给其中某个位置重新赋值。列表通常写成 [1, 2]，元组可以写成 (1, 2)。两者都可以按索引访问，也支持遍历。

不可变说的是元组中的元素引用不能被替换，并不表示其中引用的所有对象都不可变。例如元组中可以放一个列表，该列表自身仍可改变。把“元组不可变”理解为任何嵌套内容绝对不变，会导致错误。

只有一个元素的元组需要逗号，例如 (1,)；(1) 只是带括号的整数表达式。列表适合需要原地增删修改的序列；元组常用于固定组合或多值打包。选择时应依据数据语义和需要的操作，不能只凭“某一种永远更快”作决定。示例说明基本语言行为，具体程序仍应检查输入及异常。
