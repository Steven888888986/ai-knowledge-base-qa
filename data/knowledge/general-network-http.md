# 计算机网络：HTTP 请求与响应

示例问题：HTTP 请求与响应怎样交互？

HTTP 是用于客户端与服务器交换资源的应用层协议。浏览器等客户端发出请求，服务器返回响应。请求包含方法、目标资源和头部等信息，可能带有正文；响应包含状态码、头部和可能的响应正文。

GET 常用于读取资源，POST 常用于向服务器提交数据。状态码用于描述处理结果，例如 200 通常表示成功，404 表示未找到目标资源。具体接口还可能规定参数、认证方式与数据格式，单看一个状态码无法得知全部业务含义。

HTTP 的核心语义是无状态的，即协议本身不自动把每次请求连接成同一个用户会话。网站可通过 Cookie 等机制配合服务端会话管理维持状态。无状态不等于网站无法登录。HTTPS 在 HTTP 通信中加入传输加密与服务器身份验证所依赖的 TLS，不能据此推断网站内容本身一定可信。
