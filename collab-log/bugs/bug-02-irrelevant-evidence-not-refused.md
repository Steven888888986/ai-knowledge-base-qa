# BUG-02：无关片段被当成证据，系统没有拒答

- 发现方式：AI 辅助实现后的回归测试
- 严重性：高（可能回答知识库没有支持的问题）
- 状态：已修复
- 引入来源：AI 辅助实现的初版回答门控逻辑；本档案属于本次 AI 开发会话的缺陷记录，不归属于某位组员。
- 回归用例：`IsolatedAppTest.test_unknown_question_refuses_without_inventing`

## 复现

```python
app.index_document("RAG", "rag.md", "RAG 使用检索结果作为回答证据。")
result = app.answer("我今天午餐吃了什么？")
```

修复前观测到 `result["refused"] == False`：系统将不相关片段作为离线摘录回答，而不是拒答。测试断言 `self.assertTrue(result["refused"])` 失败。

## 原因与修复

初版仅依赖排序结果，没有充分区分“检索到候选”与“候选确实支持问题”。现实现要求 BM25 分数和词项覆盖同时达到最低标准，或真实 BGE cosine 与词项支持同时达标；模型生成也只接收已经筛过的证据。没有支持片段时返回明确拒答并清空引用。

## 复盘假设与证据

复盘时需区分生成模型编造答案与证据门控过宽。复现中导入的是 RAG 定义，问题询问个人午餐，二者没有支持关系；该问题在关闭生成的测试路径也出现，因此修复重点是答案前的证据筛选，不是仅修改生成 prompt。此处是事后依据现有证据整理的分析，不冒充当时逐字会话。

## 沉淀

`AGENTS.md` 要求将候选排序与答案证据判断分别验证，并保留库外拒答回归；`verify` skill 要求同时报告召回和回答正确性。没有保存的首次修复 prompt、被否定方案或 token 消耗不予补造。

## 验证

`py -3 tests/test_app.py` 的回归用例检查 `refused=True` 且 `citations=[]`。离线开发集 8 个库外问题的混合检索正确拒答率为 100%，24 个可回答问题的误拒率为 0%。
