## 复现

在项目根目录运行。以下依赖只用于生成备用视频，不影响核心问答服务：

```powershell
py -3 -m pip install Pillow imageio-ffmpeg
powershell -ExecutionPolicy Bypass -File .\scripts\start-models.ps1 -Mode all
py -3 scripts/record_demo.py
```

脚本会重新进行真实请求，覆盖日志与视频，完成后关闭独立服务并移除其临时数据库。它必须观察到本地 Qwen 回答、有效引用和正确拒答才能生成视频，不会把回退回答标为模型生成。模型的首次下载方法见 [models.md](../docs/models.md)。

仅从现有真实日志重新渲染，不再访问服务：

```powershell
py -3 scripts/record_demo.py --reuse-log
```

脚本默认使用 Windows 等线字体。其他系统可用 `--font /path/to/chinese-font.ttf` 指定中文字体；也可用 `--ffmpeg /path/to/ffmpeg` 指定已有程序。源码为 [record_demo.py](../scripts/record_demo.py)，中间 PNG 和抽帧保存在已忽略的 `.tmp/demo-video/`。
