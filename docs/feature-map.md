# 功能地图

1. 导入：Markdown/HTML/TXT/PDF/公开网页 → 清洗 → 重复 source 更新 → 保留页码的 chunks。
2. 检索：问题 → BM25 和 BGE cosine → RRF 混合排序；可切换 BM25/vector 消融模式。
3. 回答：证据阈值 → Qwen 引用生成（或离线原文摘录）→ 引用编号校验；证据不足明确拒答。纯算式单独核对原文是否明确包含该表达式及结果，有则摘录，无则拒答，不让操作数重合成为引用依据。
4. 交互：导入、删除和预览文档；输入问题、选择检索模式、查看状态、用时和来源引用。
5. 扩展：`/api/query`、`/api/ingest`、`/api/upload`、`/api/import-url`、`/api/search`、`mcp_server.py`。
6. 实时统计：HTTP 问答 → 本地模型自动评估来源与引用（失败时显式词项规则回退）→ 返回三项累计指标与分子/分母；前两项标为自动估算，人工核验可覆盖；历史快照、自动评估与人工判断分别持久化，修改与补评不重复计数。
7. 通用资料：科学、人文、经济、技术与生活等多领域内置卡片；启动时增量安装新资料包，保留用户内容与历史；可继续导入各领域原文，知识覆盖以库内资料为准。
8. 数字内容查找：纯数字输入 → 全库正文连续子串匹配 → 按文档分组，将全部命中原文片段直接列于摘要下方并高亮 → 打开原文；重叠上下文合并，不调用模型、不混入问答质量统计。
9. 拒答后生成：知识库缺少依据 → 保存拒答并更新指标 → 弹窗询问 → 否则关闭，是则 `/api/generate` 按保存的问题调用 Qwen → 单独显示无知识库依据的内容；空引用，不改写拒答或累计统计，失败可重试。
