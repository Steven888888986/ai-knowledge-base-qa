# Codex goal 工作流记录

本次使用 Codex 的 goal 工具跟踪持续任务。主会话读取到的真实工具返回保存在 [`evidence/goal-status.json`](evidence/goal-status.json)，目标原文为：

> 完成 AI 领域知识库问答系统课程项目，覆盖文件要求与验证交付，明确跳过交叉红队；模型部署和公开 GitHub 发布纳入目标。

该快照的状态是 `active`，表示当时仍在进行最终交付，并非已完成声明。它来自主会话；文档审计子线程独立读取时没有自己的 goal，不能把子线程结果作为主会话状态。

过程中的实际循环包括：按验收标准实现、执行回归与开发集评测、定位失败、修改根因、重新验证。例如 K23 的生成回答曾引用通用 RAG 资料；随后修正不同量纲分数的证据比较，增加回归测试，并重新运行完整本地生成评测。结果分别见 `tests/test_app.py` 与 `eval/local-model/`。

原始课件写的是“至少一次使用 `/goal`、`/loop` 或 `claude -p` 脚本完成任务”。这里如实记录 Codex goal 工具，不声称曾执行上述 Claude slash 命令或 `claude -p`，也不自行认定不同产品命令在课程验收上完全等价。最终任务状态应以发布结束后的工具返回为准。
