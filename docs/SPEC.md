# SPEC：通用知识库问答系统

## 背景与目标

各领域的论文、课程讲义、生活资料和工作文档分散在 PDF、网页与 Markdown 中，用户需要一个能回答问题并给出证据的本地优先工具。目标是让首次用户在 2 分钟内完成启动和提问，并能判断答案是否来自资料。

## 范围

包含文档导入、文本清洗和切分、BM25 与向量混合检索、证据片段展示、本地 Qwen 生成与引用门控、无模型时的离线证据回答、OpenAI 兼容接口、HTTP API、MCP search 工具、健康检查和统计信息。不包含交叉红队与多租户权限。

2026-11-24 根据用户追加要求，资料范围从 AI 扩展为不限领域，内置多领域入门卡片。没有宣称穷尽全领域知识，也不自动联网搜索；回答继续受当前知识库证据约束。

## 可测验收标准

| ID | 验收标准 |
|---|---|
| A1 | `py -3 server.py` 启动后 `/api/health` 返回 `ok:true` |
| A2 | 启动后至少有 1 个示例文档和 1 个片段 |
| A3 | 对“什么是 RAG”返回非空回答，且每个引用含 title/source/snippet |
| A4 | 空库或未知问题返回明确“没有找到足够证据”的拒答 |
| A5 | `/api/ingest` 重复 source 会更新文档而不是产生重复来源 |
| A6 | 页面展示 offline/llm 模式，不虚构模型调用 |
| A7 | 无 API 密钥时所有核心功能可用；PDF 在安装 pypdf 后可导入 |
| A8 | 可运行测试和 hook，README 给出复现命令 |
| A9 | 本地 Qwen/BGE 可从锁定来源下载并校验 SHA-256；本地模型不可用或输出引用无效时，系统明确回退到可核验原文，不标记为 llm |
| A10 | 每次 HTTP 问答完成时自动更新召回率 Recall@3、引用准确率、拒答率及分子/分母；前两项明确标记自动估算；本地模型不可用或判断格式无效时使用有标签的词项规则回退；无样本不显示假 0% |
| A11 | 用户可核验正确来源及逐条引用，人工判断优先于自动结果；允许标记未检索到的来源；未人工判断的引用保留自动结果；修改核验替换旧判断，不重复计数 |
| A12 | 问答快照、自动估算与人工核验分别存入本地 SQLite；刷新、重启或删除资料不清空记录；旧记录可基于保存片段补评，保留人工判断；直接调用 app.answer 的离线评测不计入网站统计 |
| A13 | 首页与 MCP 描述不限 AI，提供非 AI 示例；至少 8 个非 AI 领域的问题可在内置资料中召回正确来源，实际本地模型跨领域问答带有效引用；未收录信息仍拒答 |
| A14 | 旧数据库启动时增量加载多领域资料，不覆盖已有同来源内容、不改问答或核验历史；重复启动不增加文档，用户删除的已装入资料不会被再次自动创建 |
| A15 | 去掉首尾空格后仅含数字 `0–9` 的输入按文档正文做连续子串查找；返回所有匹配文档，每份分组列出全部命中上下文，重叠窗口合并，结果下方直接显示原文且高亮；不受检索 limit 或最多3条引用限制，支持打开原文，零匹配有明确提示 |
| A16 | 数字内容查找明确标记 lookup，不调用生成或评估模型，不新增问答记录或改变问答指标，也不误核验前次问答；含数字的完整问题继续走原问答流程 |
| A17 | 纯算式输入须有对应表达式及明确数值结果的原文证据才引用；操作数重合、较长算式的局部匹配、只有题目无结果均不能作为答案证据；无证据时拒答且引用为空，有证据时返回原文摘录，不调用生成模型补算 |

## 成功指标

离线检索的证据命中率、引用覆盖率、拒答正确率和 P95 响应时间由 `tests/test_app.py` 与人工检查记录；先保证引用覆盖率 100%，再优化模型质量。

在线累计指标与离线开发集评测分开。在线质量指标默认自动估算，可由人工纠正；有限候选池及旧检索快照无法提供全库真实召回率，页面显示评估方法与范围。拒答率是全部已完成问答中拒答的比例，不等于正确拒答率。定义与操作见 [`live-metrics.md`](live-metrics.md)。

原 `eval/` 的32题仍是 AI 主题开发集，不能当作跨领域准确率。新增跨领域验证单独记录为功能验收，使用与内置资料相关的题目，不代表独立盲测或所有领域的泛化表现。

## 非目标与风险

BM25、BGE 向量和 RRF 混合检索均可单独选择；BGE 不可用时会退回有标签的词项哈希检索。Qwen 1.5B 的生成质量有限，只有输出中引用编号有效时才接受生成回答；否则以离线原文摘录回答并显示告警。模型服务错误不会被伪装成成功调用。
